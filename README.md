# Simple React Notepad 📝

A minimal notepad application built with React in a single folder.

## Features

- Add new notes
- Edit existing notes
- Delete notes
- Responsive design
- No build step required

## How to Run

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

## Start the app:

```bash
  npm start
```

## Open http://localhost:3000 in your browser

## Technologies Used

React (with CDN - no build step!)

HTML5

CSS3
